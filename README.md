Course project for ISE 201 (Math Foundations for Decision and Data Sciences), SJSU, Fall 2025.
Dataset: ECB euro reference rates, 1999–2022 (Kaggle, `euro-daily-hist_1999_2022.csv`).

- `ISE201_Project_Proposal_Maxim_Dokukin_Revised.ipynb` — proposal
- `ISE201_EDA_Maxim_Dokukin.ipynb` — exploratory data analysis
- `ISE_201_Final.ipynb` — final analysis
